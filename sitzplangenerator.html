Sitzplan-Generator

1. Daten importieren

Alle Berechnungen laufen ausschliesslich lokal auf diesem Computer. Gespeicherte Sitzordnungen bleiben nur in diesem Browser bzw. dieser Teams-App auf diesem Gerät. Es werden keine Daten in die Cloud, an eine KI oder an einen Server übertragen.

Neu beginnen mit einer Adressliste (nur direkt aus Evento exportierte Listen, Tabellenblatt "DatenImport") oder eine gespeicherte Sitzordnung wieder aufnehmen.

Gespeicherte Sitzordnungen

Sitzordnung aus kopiertem Text laden (z.B. von einem anderen Gerät oder von einer Kollegin, einem Kollegen)
Eine früher heruntergeladene Datei "Sitzordnung.json" kann auch über den Import-Button oben geöffnet werden.

2. Lernendenperspektive

Wunschgruppen der Lernenden erfassen: Namen aus der Liste links in die gewünschte Gruppe ziehen. Nicht zugeteilte Lernende bleiben in der Liste.

3. Lehrpersonenperspektive

Im gewünschten Modus zuerst eine Person anklicken, danach weitere Personen anklicken, um sie als gut bzw. weniger gut passend zu markieren. Eine Verbindung kann nicht gleichzeitig gut und weniger gut sein: die neue Markierung ersetzt die alte. Mit "Verbindung anzeigen" für eine ausgewählte Person alle bestehenden Markierungen sehen.

gut passend weniger gut passend Ziehen mit Maustaste verschiebt ein Namensfeld, Klicken wählt aus / verbindet, Esc hebt Auswahl auf

4. Vorschlag berechnen

Automatischer Gruppenvorschlag auf Basis beider Perspektiven (Gruppengrösse: 4, siehe Schritt 2). Wunschgruppen aus Schritt 2 werden hier bereits als Ausgangslage übernommen.

5. Sichern und weitergeben

Der aktuelle Stand wird laufend automatisch gesichert und erscheint in Schritt 1 als "Zuletzt bearbeitet". Für mehrere Klassen die Sitzordnung zusätzlich unter einem Namen speichern.

Bild für die Klasse

Neutrales Bild der Gruppen (ohne Markierungen). Kopiert lässt es sich direkt in einen Teams-Chat, eine OneNote-Seite oder eine Präsentation einfügen (Ctrl+V).

Sitzordnung weitergeben oder auf ein anderes Gerät übertragen

Kopiert die komplette Sitzordnung als Text. Diesen Text z.B. in einen Teams-Chat an sich selbst oder an eine Kollegin, einen Kollegen einfügen; dort in Schritt 1 über "Sitzordnung aus kopiertem Text laden" wieder öffnen.
